# Code of conduct

Treat people with respect. Welcome questions and different experience levels, critique ideas and code rather than people, and give specific, constructive feedback. Harassment, discrimination, threats, sexualized conduct, doxxing, and sustained disruption are not acceptable.

This applies to project issues, pull requests, reviews, and other spaces maintained for the project. Maintainers may edit or remove disruptive content, close discussions, or restrict participation. Enforcement should be proportionate and explain the behavior at issue without disclosing private information.

For a conduct concern, contact the maintainer listed in [GOVERNANCE.md](GOVERNANCE.md) through a private contact route available on their GitHub profile. If no route is available, request a private channel without posting sensitive details. Do not post personal information in public issues. There is currently no independent moderation team or guaranteed response window; concerns involving the sole maintainer may need GitHub's own reporting tools.
